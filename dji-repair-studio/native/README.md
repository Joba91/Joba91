# libusb-win32 user library

libusb0.dll is the unmodified amd64 user library from official libusb-win32 1.4.0.2.
Archive and DLL SHA-256, source commit and upstream URL are recorded in
libusb0-provenance.json. LGPL/GPL texts and complete corresponding source are in
licenses/. No driver binary, driver installer or official DJI DLL is included.
The library is selected for passive reception with the existing libusb0 family
driver; the application does not install or replace drivers.
